
# Food Fest Restaurant Website

## Overview

This is a **Django-based website** that allows users to browse through various menus, each with detailed descriptions. The website features a **Contact Us** page where users can submit their queries. All queries submitted by users are stored in the **Django admin panel**, making it easier for developers or administrators to view, manage, and respond to them.

This project demonstrates a basic **Django web application** with the use of models, views, templates, and Django’s built-in **admin interface** to manage user-generated content.

## Features

- **Browse Menus**: Users can peruse different menus on the site and view their detailed descriptions.
- **Contact Us**: Users can submit queries or requests via the **Contact Us** form.
- **Admin Interface**: All queries submitted through the Contact Us form are stored in Django's built-in admin panel, where admins can easily manage the database.
- **Responsive**: The website is designed to be mobile-friendly and responsive for various screen sizes.

## Technologies

- **Django**: The web framework used for building the website.
- **Python**: The backend language for the project.
- **SQLite**: Used as the default database for storing Contact Us information entered by users.
- **HTML/CSS/Bootstrap**: For the frontend structure and styling.
